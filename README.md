# Android TV ADB for Home Assistant

A custom Home Assistant integration using a maintained fork of the `androidtv` ADB library.

## Status

In development. There is no installable integration or release yet.

The backend changes have been tested on a Sony XBR-65A8H running Android 10, with TiviMate, YouTube and Angel. Testing inside Home Assistant is still pending.
